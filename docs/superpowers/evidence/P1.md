## Design rules implemented exactly as ruled

- **One reducer commit** (`bar-deltas.ts`): leaf systems emit named contributions; sum-then-clamp-once; the composed Meal+decay tick test is the executable proof.
- **Signed pro-rata effects**: costs accrue with gains; stopping at 99% pays ~99% of the cost.
- **Nap**: startable <50 Energy; effective only in the wake-relative 60–780 window with budget; later naps restore 0 **and decay normally** (no Energy-freeze exploit); reset at wake boundary is the caller's parameter, tested.
- **Sleep**: its contribution is Energy's only writer while asleep; +10/h scaled by nothing.

## Remaining risks / later owners

- The engine loop that sequences these pieces (anchors, planner, travel) is P2 — P1 deliberately ships no placeholder engine.
- Fill rounding uses decimal round-half-up for `fillStartTick` (documented in `activities.ts`); P2's golden replays will freeze it behind `ENGINE_VERSION`.
- Practice scoring consumes `m_out`/Well-fed/Minty-fresh in P2 per the round-3 Q1 ruling.
