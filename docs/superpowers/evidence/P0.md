## Kill-gate record: expo-sqlite web is out; KV adapter is in

The plan named Task 4 a kill gate and it fired:

1. **CanvasKit path.** `LoadSkiaWeb()` fetched `/_expo/static/js/web/canvaskit.wasm` (404). Fix: `locateFile: (f) => '/' + f` against the root copy `setup-skia-web public` installs (the CLI errors without the explicit `public` argument).
2. **expo-sqlite on web.** With isolation true and the wa-sqlite wasm present in `dist/assets/…`, `openDatabaseAsync('proof.db')` hung indefinitely (instrumented: stuck at "opening…"; its blob worker never fetched wasm). Official docs: web support "is in alpha and may be unstable"; our setup matched their stated requirements, so this is the documented instability, not a config error.
3. **Ruling:** persistence sits behind `src/persistence/kv.ts` — web driver `kv-driver.web.ts` (localStorage; v1 persists one small versioned blob, SPEC §15), native driver `kv-driver.ts` (expo-sqlite, failed-open cache cleared so one transient error can't poison the session). Recorded in SPEC §3 + §15.

## The evidence-PNG incident (critic round 1 BLOCKER, resolved)

The first committed `p0-skia-canvas.png` was a **blank, malformed capture** — a cross-frame WebGL `toDataURL()` against a non-preserved buffer, corrupted further by a shell round-trip — and the evidence described it as showing the rect. That was exactly the "rehearsed rather than observed" failure this file exists to prevent. Resolution:

- Skia 2.6.2's `makeImageSnapshot` returns `undefined` against the web surface and `makeImageSnapshotAsync` rejects ("Failed to make image snapshot") — both verified in the exported page.
- The committed artifact is now an **offscreen CanvasKit rasterization produced inside the exported page** (`MakeSurface(128,128)` → same cream clear + terracotta rect → `encodeToBytes`), transported base64-safe, then **pixel-verified before commit**: CRC-valid chunks, IEND present, center pixel exactly (188,107,66), corner exactly (242,228,194).
- The on-screen render was witnessed live (full-page screenshot in the session transcript). Scope honesty: the PNG proves the exported page's CanvasKit rasterizes correctly; the on-screen witness is the transcript screenshot. `ProofScreen` also exposes `__captureProofPng()` (same-frame redraw+copy) for a visible-pane capture; it cannot run while the pane is hidden (rAF suspended) — which is why the offscreen route is the durable artifact.
